# Paper Trading End-to-End V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Composer un parcours durable qualification → candidat → BUY paper → dix achats externes → SELL paper, coté passivement sur Pump.fun puis PumpSwap, sans aucune capacité d'exécution Solana.

**Architecture:** Le pipeline Solana enfile un job déterministe après ses projections canoniques. Un worker avec lease reconstruit les faits sous snapshot PostgreSQL, lit des quotes passives à un slot commun, évalue et persiste qualification/candidat/session puis appelle le ledger paper existant. Le mode observe conserve les projections de décision mais court-circuite toutes les écritures de session et de position paper.

**Tech Stack:** TypeScript strict ESM, Node test runner, PostgreSQL, `@solana/web3.js`, `@solana/spl-token`, `@pump-fun/pump-sdk@1.36.0`, SDK PumpSwap officiel, bigint/NUMERIC(78,0), API HTTP V1 et SSE durable.
