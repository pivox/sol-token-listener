# Contrats API V1

## Statut

Contrat cible pour un front-end indépendant. Les routes ne sont pas encore
servies par la PR A. L’API sera publique, en lecture seule et versionnée sous
`/api/v1`.

Tous les montants entiers potentiellement supérieurs à `Number.MAX_SAFE_INTEGER`
sont des chaînes décimales. Les dates sont ISO 8601 UTC. Les champs nouveaux
seront ajoutés de façon compatible ; un changement incompatible utilisera une
nouvelle version d’API ou de payload.

## Routes

| Route | Projection |
| --- | --- |
| `GET /api/v1/launches` | radar paginé des lancements |
| `GET /api/v1/launches/:mint` | fiche normalisée et état courant |
| `GET /api/v1/launches/:mint/events` | timeline ordonnée par curseur |
| `GET /api/v1/launches/:mint/risk` | scores, blockers, verdict et preuves |
| `GET /api/v1/launches/:mint/social` | liens et preuves publiques |
| `GET /api/v1/launches/:mint/holders` | concentration et clusters observés |
| `GET /api/v1/paper-positions` | positions et PnL simulé |
| `GET /api/v1/health` | état RPC, checkpoints, lag et composants |

Les listes utilisent `?limit=` et `?cursor=`. Le curseur est opaque ; le client
ne doit ni le construire ni l’interpréter.

## Enveloppe

```json
{
  "apiVersion": "v1",
  "data": {},
  "meta": {
    "generatedAt": "2026-07-28T12:00:00.000Z",
    "nextCursor": null
  }
}
```

Une erreur utilise un code stable :

```json
{
  "apiVersion": "v1",
  "error": {
    "code": "LAUNCH_NOT_FOUND",
    "message": "Launch not found."
  }
}
```

## Événements temps réel

Le transport V1 recommandé est Server-Sent Events :

```text
GET /api/v1/events
Accept: text/event-stream
Last-Event-ID: <opaque-domain-event-id>
```

Chaque trame :

```text
id: evt_<sha256>
event: QualificationUpdated
data: {"payloadVersion":1,"mint":"base58","confirmationStatus":"confirmed","payload":{}}
```

Le serveur doit :

- persister l’événement avant diffusion ;
- reprendre strictement après `Last-Event-ID` ;
- envoyer un heartbeat ;
- fermer explicitement avec une erreur si le curseur est expiré ;
- ne jamais masquer une lacune de reprise ;
- diffuser les corrections `finalized` et `orphaned`.

Une reconnexion sans curseur ne garantit que les événements disponibles dans la
fenêtre de rétention. Le front-end recharge alors les projections HTTP.
